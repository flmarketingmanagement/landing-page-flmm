Block theme de FL Marketing Management.

== Description ==

Theme sobrio y bilingüe (EN por defecto, ES con Polylang) para flmarketingmanagement.com.
Incluye plantillas de servicio, blog con índice lateral, patrones editables en EN y ES,
bloques dinámicos para header, footer y contacto, GTM configurable y datos estructurados
que no se duplican con el plugin SEO.

Es un theme privado: no se publica en WordPress.org. Por eso registra bloques propios
(register_block_type), algo que el directorio de themes reserva a los plugins.
